# رَسم Studio
محرّر Whiteboard عربي RTL يحوّل مجموعة صور مرقّمة إلى فيديو متتابع بالتعليق الصوتي. التطبيق static ويعمل داخل المتصفح. يمكن فتحه للزوّار من غير تسجيل أو مفاتيح API.

## النشر على Vercel
فك ضغط المشروع وارفع محتويات المجلد إلى مستودع Git. من Vercel اختر New Project واستورد المستودع. اجعل Root Directory هو المجلد الذي يحتوي على package.json وvercel.json. الإعدادات المرفقة تختار npm run build ومجلد dist تلقائيًا. بعد Deploy افتح رابط Production من نافذة خاصة للتحقق من وصول الزوّار حسب إعدادات الحساب.
للنشر من Terminal بعد تسجيل الدخول إلى Vercel شغّل npx vercel --prod من جذر المشروع.

## التشغيل المحلي
يتطلب أمر التطوير Node.js حديثًا. شغّل npm run build ثم npm run dev وافتح http://localhost:3000. لا توجد حزم تشغيل خارجية. ملفات التطبيق الكاملة موجودة في dist وهي ملفات المصدر نفسها.

## إنتاج أول فيديو
1. ارفع الصور معًا بأسماء مرقّمة. أول دفعة تستبدل المشروع التجريبي. الدفعات التالية تضاف بعد التسلسل الحالي.
2. اختر مشهدًا من الشريط. عدّل اسمه ومدته ونسبة الثبات والانتقال والخلفية وأسلوب الرسم واليد. يمكن تكراره وتحريكه واسترجاع المشهد المحذوف في الجلسة.
3. لاستخدام تصوير حقيقي لليد ارفع PNG شفافًا تملك حق استخدامه. اضبط نسب موضع رأس القلم من أعلى يسار الصورة. ملف اليد ونقطة القلم مشتركان بين المشاهد التي تستخدم اليد المخصصة.
4. أضف التعليق الصوتي، ثم اضبط مدد المشاهد حسب التسجيل. يبدأ التسجيل مع الفيديو وينتهي عند نهاية مساره أو نهاية الفيديو، أيهما أقرب.
5. اختر مقاس الفيديو ودقته. اترك نافذة التصدير في المقدمة حتى يتاح رابط التنزيل. صيغة الملف حسب المتصفح، MP4 أو WebM.
6. من «ملف المشروع» نزّل ملف .rasm لنقل شغلك. يتضمن صور العمل والتسجيل والإعدادات. يُحفظ المشروع في IndexedDB كملفات صور وصوت (Blob) دون تحويل base64، ويطلب المحرر تخزينًا دائمًا من المتصفح. إذا تعذّرت استعادة مشروع محفوظ تُحفظ منه نسخة باسم recovered-* ولا يُكتب فوقه. يسترجع المحرر آخر مشروع على نفس المتصفح والعنوان. في التصفح الخاص قد تزول البيانات عند الإغلاق.

## تركيب المشروع
- dist/index.html وdist/style.css لواجهة المحرّر المتجاوبة.
- dist/app.js للمعاينة والرسم على Canvas وتسجيل الفيديو.
- dist/engine.js وdist/engine-worker.js لاستخلاص مسارات الحواف (يعمل داخل Web Worker).
- dist/motion.js لترتيب المسارات وجدول كشف الألوان وقرار ظهور الإيد، وdist/zones.js لمحرّر المناطق.
- dist/project.js للحفظ والاسترجاع (IndexedDB) وWeb Audio والتسجيل المدمج واليد المخصصة.
- dist/reliability.js لأدوات تسلسل عمليات الحفظ وحساب أبعاد الصور وحدود الذاكرة.
- scripts/ فحوص الربط والاختبارات (check وengine-test وmotion-test وschedule-test) وخادم التطوير. تشغيلها كلها بـ npm run build. الأمر لا يولّد ملفات، لأن dist هو المصدر نفسه.

## خصائص التشغيل
مسارات الرسم مستخرجة من تباين البكسلات. الصور الخطية تعطي نتائج أنظف من الصور الفوتوغرافية. تُصغّر صور العمل داخل مساحة 960×720 بكسل كحد أقصى مع حفظ النسبة، ولا تُكبَّر الصور الأصغر. اختيار 1080p يحدد أبعاد الفيديو النهائي. التصدير محلي بالزمن الحقيقي ويتأثر بأداء الجهاز ودعم MediaRecorder. الحفظ الحالي فردي على الجهاز. التخزين السحابي والتعاون المتزامن والرندر في الخلفية خارج هذه النسخة.

## إصدار 4.0 — محرك الصور
يستخدم محرك الصور الجديد Gaussian blur وSobel وNon-maximum suppression وربط الحواف بعتبات مزدوجة، ثم يتتبع المسارات مع حماية حدود الصورة. تُبسّط المسارات وتُعاد عينتها للحفاظ على حركة رسم متدرجة. التحليل يعمل داخل Web Worker في المتصفحات الداعمة، مع مسار احتياطي متزامن. مساحة تحليل الصور تصل إلى 960×720 مع الحفاظ على النسبة.
المحرّك الجديد يحسّن استخراج الخطوط، لكنه لا يطبق بعد فهمًا دلاليًا للأشخاص أو المنتجات أو فصل الخلفيات. لا تزال هذه مرحلة تأسيسية لتحسين محرك الصور.

## إصدار 3.0
الإيد الافتراضية فوتوغرافية بماركر أبيض وأسود. لكل مشهد حجم مستقل وإعداد «الإيد في الصورة الأصلية». في الإصدار 3.2 يُظهر الفحص تنبيهًا فقط افتراضيًا. يمكن اختيار الإخفاء عند الاشتباه لكل مشهد. الفحص يعتمد على لون ومساحة منطقة متصلة بحافة الصورة، وقد يلتبس عليه الخشب أو يفوّت يدًا بقفاز. اختر «الصورة فيها إيد بالفعل» لإيقاف طبقة الإيد المتحركة في المعاينة والتصدير، أو «الصورة من غير إيد تصوير» لتفعيلها يدويًا. تظل إيد الصورة الأصلية جزءًا من الرسم. صور الأقلام والأيدي المخصصة تُستخدم كما رفعها المستخدم.
من «ترتيب مناطق الرسم» حدّد عناصر المشهد بمستطيلات متتالية. تُرتّب المسارات بحسب موقع منتصف كل مسار، وتُرسم المناطق المتداخلة بأولوية أول منطقة. يدعم هذا الإصدار استيراد ملفات 2.0 وتنزيل ملفات 3.0. ملف motion.js يحسب ترتيب المسارات وقرار ظهور الإيد. ملف zones.js يدير محرّر المناطق.


## حدود الاستيراد
حتى 150 صورة في المشروع، وكل صورة حتى 25 ميجابايت، وحد إجمالي 48 مليون بكسل بعد التصغير إلى 960×720، والتسجيل الصوتي حتى 80 ميجابايت. تظهر حالة معالجة الدفعة ويمكن إلغاء الاستيراد بعد انتهاء الصورة الجاري تحليلها.
