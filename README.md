# رَسم Studio 5.2.3
محرّر عربي لتحويل مجموعة صور إلى فيديو وايت بورد مع يد رسم وتعليق صوتي.

## ابدأ
1. استورد الصور. الأرقام في أسماء الملفات تحدد ترتيب أول دفعة.
2. أضف التسجيل من «التعليق الصوتي». استخدم «مطابقة الفيديو مع مدة التسجيل» لضبط المدة الإجمالية، ثم راجع توقيت كل مشهد.
3. اختر المشهد من المخطط الزمني وعدّل خصائصه. اسحب حافته لتعديل مدته.
4. من «التصدير» اختر أبعاد الفيديو ودقته وصيغته، ثم اضغط «تصدير الفيديو».
5. بعد الانتهاء عاين الملف الناتج واضغط «تنزيل الفيديو».

## تشغيل المشروع
يتطلب تشغيل الأوامر Node.js 20 أو أحدث. ثبّت الاعتمادات مرة واحدة باستخدام npm install؛ يعتمد المشروع على OpenCV.js وPaper.js بإصدارات ثابتة، ويُنسخ إصدار المتصفح المحلي منهما إلى dist/vendor عند البناء.
- npm run build يفحص صحة الملفات، والربط بالواجهة، ومحركات الصور والمسارات، وخادم التطوير.
- npm run dev يشغّل المحرّر على http://localhost:3000.
- لإعداد منفذ مختلف، استخدم npm run dev -- --port 4173.
افتح التطبيق عبر http://localhost أو HTTPS حتى تتوفر واجهات الترميز في المتصفح. فتح index.html مباشرة بصيغة file:// يعطل Workers والوحدات البرمجية.

## النشر على Vercel
ارفع ملفات هذا المجلد إلى المستودع. استورد المستودع في Vercel واجعل Root Directory هو المجلد الذي يحتوي على package.json. يحدد vercel.json أمر npm run build ومجلد dist. جميع مكتبات التشغيل والخطوط مرفقة. لا توجد مفاتيح API مطلوبة. اختبر الرابط النهائي من جهازك، لأن دعم الترميز يعتمد على المتصفح ونظام التشغيل.

## محرك تحليل الأشكال في 5.2

يعتمد تحليل الصور على OpenCV.js 5.0.0 لاستخلاص المكونات بعد المعالجة المورفولوجية وتجميع العلامات القريبة، وعلى Paper.js 0.17.0 لتحسين تبسيط المسارات الهندسية. المكتبتان مثبتتان في package.json ويُنسخ ملفاهما إلى dist/vendor وقت البناء؛ لا يوجد اعتماد على CDN أثناء التشغيل.

يحوّل محرك الأشكال مكونات الصورة إلى مجموعات، ويربط كل مسار بمجموعة، ثم يرتب مسارات القلم داخل الشكل الواحد. ينتقل القلم إلى الشكل التالي بعد إنهاء مسارات الشكل الحالي. خريطة rasterLabels تربط كل بكسل بالشكل الذي ينتمي إليه، ويستخدمها جدول الكشف لمنع انتشار ظهور بكسلات شكل مجاور مبكرًا. الوضع الافتراضي «تجميع ذكي»، ويمكن اختيار «مسارًا بمسار». ترتيب مناطق الرسم الذي يحدده المستخدم يتقدم على الترتيب التلقائي.

التجميع هندسي قائم على الاتصال والقرب والمسافات، وليس فهمًا دلاليًا عامًا لمحتوى الصورة. الرسوم المتداخلة أو الأجزاء البعيدة التي تنتمي معنويًا إلى كائن واحد قد تحتاج تحديد مناطق يدويًا. الصور الفوتوغرافية والخلفيات غير المتجانسة قد تستخدم المسار الاحتياطي إذا لم تكن خريطة المكونات موثوقة.

## تحليل العناصر في 5.2.3

تقسيم الصورة يعتمد على المكونات المتصلة. تُجمع العلامات الصغيرة المنفصلة عندما تتوافق مع قاعدة الحرف، وتُجمع الأجزاء التي تقع داخل إطار مغلق مثل سحابة أو فقاعة أو شارة مع الإطار نفسه. لا تُدمج العناصر المتجاورة لمجرد قرب حدودها. يبقى النص أو الرسم الواقع خارج الإطار عنصرًا مستقلًا.

جدول كشف الصورة يستخدم الاتصال الثماني، وهو نفس تعريف الاتصال المستخدم في تقسيم OpenCV. لذلك تنتشر عملية الكشف إلى البكسلات المتصلة قطريًا بدل تركها كأجزاء متأخرة.

إذا لم ينتج عنصر مسار centerline، يستخدم المحرك مسارات الحواف الخاصة بالمكوّن نفسه. وإذا لم توجد مسارات حواف أيضًا، يُنشئ مسحة قلم قصيرة داخل حدود المكوّن حتى لا يتأخر ظهوره حتى نهاية المشهد.

تظل حدود التقسيم هندسية وليست فهمًا دلاليًا كاملًا؛ الرسومات المتلامسة التي لا تحتوي فاصلًا بصريًا واضحًا قد تحتاج إلى تحديد مناطق يدويًا.

## حركة اليد
الوضع الافتراضي «مسارات رئيسية» يرتب مسارات قريبة من بعضها، ويحرك القلم بحسب المسافة الحقيقية. في الصور الملوّنة، يختار المسارات الأطول لتقليل تتبع تفاصيل الملمس. تظهر بقية ألوان الصورة في نهاية الرسم. وضع «تفاصيل دقيقة» يحتفظ بالمسارات التفصيلية. في الرسم الخطي تحتفظ الأداة بكل المسارات، ولذلك تتطلب الصور كثيرة التفاصيل وقتًا أطول.

مدة المشهد هي مدته على المخطط الزمني. تغيير سرعة الرسم يزيد أو يقلل هذه المدة. راجع التزامن بعد تغيير السرعة. ترتيب مناطق الرسم يسمح بإعطاء أولوية لعناصر محددة داخل الصورة.

الفحص التقريبي للون اليد يعطي تنبيهًا فقط افتراضيًا. اختر «الصورة تتضمّن يدًا» لمنع ظهور يد إضافية في الصور التي تحتوي أصلًا على يد. يمكن رفع PNG ليد مخصصة وضبط إحداثيات رأس القلم.

## التصدير
المحرك الدقيق يستخدم Mediabunny 1.66.2 وWebCodecs، ويُنشئ كل إطار بتوقيته المحدد. سرعة المعالجة لا تحدد سرعة الفيديو. يُرمَّز الصوت على نفس خط الزمن، ويُدمج مع الصورة في ملف واحد. يختار الوضع التلقائي MP4 إن توفر AVC وAAC، وإلا WebM باستخدام VP8 وOpus. تظهر رسالة واضحة إذا لم يدعم المتصفح الصيغة المختارة.

عند غياب WebCodecs يستخدم التطبيق التسجيل المتوافق، ويمكن اختياره يدويًا. التسجيل المتوافق يعمل بالزمن الحقيقي ويتطلب إبقاء الصفحة في المقدمة. إذا انتقلت الصفحة للخلفية، يتوقف مع رسالة بدل اعتماد ملف قد تكون صورته متجمدة. في المحرك الدقيق قد تتباطأ المعالجة في الخلفية، ويستمر توقيت الفيديو النهائي مضبوطًا.

الفيديو ينتهي عند نهاية المشاهد. إذا كان التسجيل أطول، فالجزء الزائد لا يدخل الفيديو. يظهر اختلاف المدتين أسفل مسار الصوت مع زر لمطابقتهما. دقة 1080p هي دقة ملف الفيديو، وتُصغّر صور التحليل إلى مساحة أقصاها 960×720 للحفاظ على الاستجابة. ملفات التصدير تُجمع في ذاكرة الجهاز.

## حفظ المشروع
الحفظ التلقائي داخل IndexedDB في المتصفح الحالي. لنقل المشروع، استخدم «إدارة المشروع» ثم «تنزيل نسخة المشروع». ملف .rasm يشمل صور العمل والصوت والإعدادات. يدعم استيراد إصدارات المشروع 2 و3 السابقة. تتوفر استعادة المشهد المحذوف خلال الجلسة. زر «مشروع جديد» يحفظ المشروع الحالي ضمن «مشروعات سابقة ونسخ مستردة» قبل إفراغ مساحة العمل. استيراد أول دفعة صور يستبدل المثال التجريبي، والدفعات التالية تضاف إلى مشروع المستخدم.

## هيكل الملفات
- dist/engine.js وengine-worker.js لاستخلاص مسارات الصورة، مع dist/shape-engine.js لتجميع المكونات في أشكال.
- dist/motion.js وmotion-worker.js لترتيب حركة الأشكال ومزامنة كشف البكسلات مع مسار اليد.
- dist/offline-export.js للتصدير الدقيق، وlive-export.js للتسجيل المتوافق.
- dist/app.js للمعاينة والمخطط الزمني، وproject.js لملفات المشروع والصوت والحفظ.
- dist/interface.js للبدء التدريجي وأقسام الخصائص ومطابقة مدة الصوت.
- scripts/ لاختبارات المشروع وخادم التطوير.
- dist/vendor/ يحتوي نسخ Mediabunny وOpenCV.js وPaper.js المحلية، وبيانات الإصدارات والبصمات والتراخيص.
- dist/assets/ يحتوي صورة اليد والخطوط وتراخيصها.

## الاختبارات العملية
توجد نتيجة المراجعة وحدود الاختبار في QA-REPORT.md. شُغلت النسخة في Chrome على Linux، واختُبرت ملفات الفيديو الناتجة باستخدام FFmpeg. يلزم اختبار قبول مستقل على Safari/iPhone قبل إعلان دعم كل الأجهزة.

## واجهة الموبايل في 5.1
على الشاشات بعرض 900 بكسل أو أقل تظهر الإعدادات داخل قائمة جانبية تفتح من زر القائمة أعلى الشاشة أو من «إعدادات المشهد». تحتوي القائمة على إدارة المشروع والاستيراد والتعليق الصوتي وأقسام الخصائص وزر التصدير. «العودة للمعاينة» يغلقها مع الاحتفاظ بالتعديلات. عند توسيع النافذة تعود لوحة الخصائص إلى مكانها على الكمبيوتر، باستخدام عناصر التحكم نفسها.
تُقفل القائمة أثناء المعالجة والتصدير، وتُعاد بعد اكتمال العملية. يتوفر زر تنزيل مباشر داخل نتيجة التصدير. اختُبر التخطيط بعرض 320 و390 و1100 بكسل في Chromium، مع اختبار تصدير من القائمة.

عند تعديل المشروع بعد التصدير، تظهر إشارة إلى أن الفيديو المعروض نسخة سابقة تحتاج إعادة التصدير لتضمين التعديلات.
